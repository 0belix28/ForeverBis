# ForeverBis
Tes B.I.S (Best in Slot) sur WoW Forever, calculés pour ton personnage : pendant le leveling et au niveau 60.  ForeverBis regarde ta classe, ton niveau, ta faction et tes talents, puis te montre la meilleure pièce que tu peux obtenir pour chaque emplacement. Il les signale aussi directement dans les bulles d'objets.
